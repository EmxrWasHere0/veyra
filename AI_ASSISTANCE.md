# AI Assistance

AI tools have been used as supplementary aids during the development of Veyra and its supporting projects.

## Areas of Assistance

AI tools have helped with:

- Investigating bugs and discussing possible fixes.
- Drafting and refining code and regression tests.
- Drafting, editing, and organizing documentation.
- Configuring and troubleshooting GitHub Actions.
- Reviewing test output and exploring implementation choices.

Some material in this repository may have originated as AI-generated suggestions or drafts.

## Tools Used

- **[ChatGPT](https://chatgpt.com)** — Used for debugging, code and test suggestions, documentation drafts, and GitHub Actions assistance.
- **[Arena](https://arena.ai)** — Used to compare responses from multiple models while exploring debugging approaches.

## Human Review

AI-generated suggestions can be incorrect or incomplete. Maintainers review and adapt suggestions before incorporating them, and test code changes where applicable. Project contributors remain responsible for the final code, documentation, and release decisions.

No autonomous coding agents were used during development. AI assistance was provided through human-directed interactions.

This disclosure describes the project's use of AI to date and may be updated as that use changes.
