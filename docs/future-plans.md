# Future Plans

Veyra is an experimental programming language that continues to evolve.

With version 0.2.6, the language includes an interactive REPL, user-defined modules, expanded built-in libraries, automated tests, and improved developer tools.

The following ideas are being considered for future development.

## Language Improvements

- **String interpolation** — Embed expressions directly inside strings.
- **Pattern matching** — Introduce structured matching for values and conditions.
- **Functional collection methods** — Explore operations such as `map`, `filter`, and `reduce`.
- **Additional built-in utilities** — Expand existing modules where useful.

## Developer Experience

- **Improved diagnostics** — More precise error locations and clearer suggestions.
- **Editor integration** — Explore autocomplete, diagnostics, and navigation features for the VSCode extension.
- **Documentation improvements** — Keep language references, examples, and tutorials up to date.
- **Testing improvements** — Expand automated regression coverage and improve test reporting.

## Performance

- **Interpreter optimizations** — Improve execution speed and memory efficiency.
- **Runtime profiling** — Investigate performance bottlenecks and optimize frequently used operations.

## Long-Term Possibilities

- **Standalone executables** — Explore compiling Veyra programs into native executables.
- **Hybrid execution** — Investigate supporting both interpreted and compiled execution.

These are potential directions rather than confirmed features or release commitments.

Veyra's development priorities may change based on experimentation, implementation complexity, and community feedback.
