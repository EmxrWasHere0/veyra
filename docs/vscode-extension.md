## VSCode Extension

Syntax highlighting, snippets, and basic language configuration are available as a separate extension. See [`veyra-vscode`](https://github.com/EmxrWasHere0/veyra/tree/main/veyra-vscode) in this repository or install from source:

```bash
cd veyra-vscode
npm install -g @vscode/vsce
vsce package
code --install-extension veyra-0.2.0.vsix
```
