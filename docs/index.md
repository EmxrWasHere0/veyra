# Veyra Documentation

Welcome to the official documentation for **Veyra**, a small, dynamically typed, interpreted programming language with easy-to-understand keywords and a unique channel mechanism for runtime value overrides.

Use the guides below to install Veyra, learn its syntax, explore its built-in modules, and build your own programs.

## A Quick Example

```veyra
set port = 8080
port = 3000

say port
say 0 ? port
```

This example demonstrates a constant and its channel override.
