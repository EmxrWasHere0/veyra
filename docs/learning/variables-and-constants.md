# Variables and Constants

## Variables

Regular variables are created by assignment and are **dynaically typed**:

```text
x = 5
x = "I'm now a string!"
x = [1, "Look mom, I'm a list now!", true]
```

## Constants

Constants are declared with `set` and **never change**

```text
set PI = 3.14
set MSG = "You can't change me heehee!"
```
