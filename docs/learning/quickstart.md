# Quickstart

To start coding with Veyra, you need to create a Veyra file first. Veyra's original extensions are:

```text
.vey
.vy
.veyra
```

You can also run other file extensions containing Veyra syntaxes.

We recommend opening the file you created with VS Code since we have a VS Code syntax highlighting extension given in our repository.

[Click here](https://github.com/EmxrWasHere0/veyra/raw/refs/heads/main/veyra-vscode/veyra-0.2.0.vsix) to install the extension.
